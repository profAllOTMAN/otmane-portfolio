The Challenge

UX documentation is scattered across too many tools

Traditional UX documentation and auditing processes are fragmented across multiple disparate tools — Figma for designs, Jira for tracking, PowerPoint for stakeholder presentations, and Google Docs for findings. Teams lose context, face formatting inconsistencies, and waste hours exporting and reformatting findings manually.

Fragmented Scattered across 4+ tools
Manual Hours lost to reformatting
Inconsistent No single source of truth
The Solution

One platform for the entire UX workflow

I designed and built DocuFlow — a unified platform that brings design documentation, annotation, organization, and multi-format export into a single React-based application. Teams can maintain a living, easily distributable record of their product's user experience without ever leaving the tool.

01

Nested Navigation System

Designed a hierarchical navigation structure that handles complex product ecosystems — from top-level product areas to individual screens and audit findings.

02

Embedded Image Cropping

Built-in image cropping tools let practitioners focus on specific screen areas without switching to external editors — streamlining the documentation of UI findings.

export → HTML report export → PDF document export → Word (.docx) export → PowerPoint (.pptx)
03

Multi-Format Export

One-click export to HTML, PDF, Word, and PowerPoint using pptxgenjs for programmatic slide generation — targeting every stakeholder's preferred format directly from the browser.

Process

From problem to shipped product

This project required both product thinking and hands-on engineering — designing the UX workflow and building it end-to-end with modern React.

1

Problem Research

Mapped the fragmented UX documentation workflow — identifying pain points across tools, export friction, and context loss between design, documentation, and presentation phases.

2

Information Architecture

Designed a nested navigation system that mirrors how UX teams organize their work — product areas, screens, findings, and recommendations in a clear hierarchy.

3

UI Design & Prototyping

Created the interface with a focus on documentation clarity — clean typography, focused image cropping, annotation tools, and a consistent visual system using Tailwind CSS.

4

Development & Shipping

Built the full application with React 18, TypeScript, Tailwind CSS, and Framer Motion. Implemented browser-based multi-format export with pptxgenjs. Deployed to Vercel.

Outcome

Key takeaways

Single source of truth for UX documentation

Teams can organize, annotate, and distribute UX findings through one interface — eliminating context switching between Figma, Jira, and PowerPoint.

Reduced audit cycle time

Built-in image cropping and multi-format export eliminate manual reformatting — maintaining a living, easily distributable record of product UX.

Designer who ships = full ownership

Designed the UX and built the full React application end-to-end — from problem research to live deployment on Vercel.
