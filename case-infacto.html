The Challenge

Making invoice financing intuitive for investors

Invoice financing is a complex financial product. Investors need to quickly evaluate opportunities, understand risk levels, and track their portfolio performance — all while dealing with dense financial data. The challenge was to make this experience clear, transparent, and easy to navigate.

Complex Dense financial data to simplify
Trust Investors need data transparency
MVP Ship fast, iterate with real users
The Solution

A complete investor experience

I designed and helped implement a scalable design system and the full investor-side experience — from portfolio overview dashboards to individual invoice detail views. The focus was on data transparency and intuitive navigation to enhance investor decision-making.

01

Data Visualization Dashboards

Designed financial dashboards using ApexCharts to present portfolio performance, investment returns, and invoice status — improving clarity and financial insight for investors.

02

Scalable Design System

Built a comprehensive design system with color tokens, typography scale, reusable UI components, and design guidelines — ensuring consistency across the entire platform.

03

Design-to-Code with Tailwind

Translated UX flows into reusable UI components and implemented key interfaces using HTML, CSS, Tailwind CSS, and JavaScript — bridging the gap between design and development.

Process

From UX flows to implemented UI

This project required both design thinking and hands-on implementation — going beyond Figma into actual frontend code.

1

UX Flows & Architecture

Mapped investor journeys — from onboarding to portfolio management to individual invoice evaluation — prioritizing intuitive navigation throughout.

2

Design System Creation

Defined color tokens, typography, spacing, and built a library of reusable UI components in Figma to ensure visual consistency across the platform.

3

Dashboard & Data Viz

Designed and configured data visualization dashboards using ApexCharts to present financial tracking and operational insights clearly.

4

Frontend Implementation

Implemented key interfaces using HTML, CSS, Tailwind CSS, and basic JavaScript — translating Figma components directly into production-ready code.

Outcome

Key takeaways

Design system that scales

The component library and token system provided a solid foundation for the platform to grow beyond the initial MVP without design debt.

Data transparency builds trust

Clear data visualization dashboards gave investors the confidence to make informed decisions, with financial metrics presented in an accessible format.

Designer who codes = faster delivery

Being able to go from Figma to Tailwind implementation directly eliminated handoff friction and accelerated the MVP timeline.
